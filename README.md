# Kenzai Intelligence organization profile

This special `.github` repository contains the public organization profile and default community-health files for Kenzai Intelligence.

- Organization profile: [`profile/README.md`](profile/README.md)
- Security policy: [`SECURITY.md`](SECURITY.md)
- Contribution guidance: [`CONTRIBUTING.md`](CONTRIBUTING.md)

Company website: [kenzai.io](https://kenzai.io)

## Profile artwork

The SVGs in `profile/assets/` are unmodified copies of the current [Kenzai website brand assets](https://kenzai.io/brand-guidelines). The profile uses `kenzai-lockup-primary.svg` and `kenzai-mark-primary.svg` on light backgrounds, with the corresponding `-reverse.svg` files for dark mode.

Refresh these files from `https://kenzai.io/brand/` when the approved website identity changes. Preserve their colours, paths, spacing, and aspect ratios. The previous JPGs remain available for existing external links.
